方劑組成解釋

白朮

1 / 11

藿香正氣散中包含白朮，主要原因如下：

  1. 健脾燥濕：白朮性溫，味甘苦，具有健脾燥濕的功效，能增強脾胃運化功能，改善濕邪困脾所致的腹脹、泄瀉等症狀。藿香正氣散主治濕濁內阻，脾胃不和的症狀，白朮可助其祛濕健脾，增強療效。
  2. 和中理氣：白朮還具有一定和中理氣的作用，能緩解脾胃氣滯所致的胸悶、腹痛等症狀，配合藿香、佩蘭等理氣藥物，共同發揮協同作用，達到更佳的治療效果。

藿香

2 / 11

藿香正氣散中包含藿香，主要原因如下：

  1. 芳香化濕： 藿香性辛溫，具有芳香化濕之效，可驅散暑濕，消解脾胃濕熱，適用於暑濕內侵，脾胃不和所致的腹痛、腹瀉、嘔吐等症狀。
  2. 解表止嘔： 藿香亦能解表散寒，止嘔逆，對於暑濕夾寒、脾胃氣逆引起的嘔吐也有良好療效。

因此，藿香作為藿香正氣散的主要藥材，能有效治療暑濕所致的各種症狀，是其方劑中不可或缺的重要組成部分。

半夏

3 / 11

藿香正氣散中加入半夏，主要有以下兩個原因：

  1. 燥濕化痰：半夏味辛、性溫，具有燥濕化痰的功效。藿香正氣散主治暑濕感冒，半夏可幫助祛除濕邪，化解痰飲，使患者症狀得以緩解。
  2. 降逆止嘔：半夏還具有降逆止嘔的功效，可緩解暑濕引起的胃氣上逆、噁心嘔吐等症狀。配合藿香、佩蘭等芳香化濕藥，更能有效地止嘔降逆，恢復胃氣功能。

陳皮

4 / 11

藿香正氣散中加入陳皮，主要有兩大原因：

  1. 理氣和胃，增強藥效： 陳皮味辛、苦，性溫，入脾、肺經，具有理氣化痰、燥濕健脾的功效。其能疏肝理氣，促進腸胃蠕動，增強脾胃消化功能，使藿香正氣散的藥效更易發揮，更好地達到解表化濕、理氣和中的效果。
  2. 調和藥性，防止副作用： 藿香正氣散中含有多種辛溫藥物，易燥烈，而陳皮性溫，能調和藥性，避免藥物過於燥熱傷陰，起到緩和作用，使藥物更安全有效。

大腹皮

5 / 11

藿香正氣散中加入大腹皮，主要基於以下兩個原因：

  1. 理氣健脾，化濕止瀉: 大腹皮性平味辛，具有理氣健脾、燥濕化痰之效。與藿香、厚朴等藥物協同作用，能有效化解暑濕之邪，止瀉止嘔，緩解脾胃氣滯、濕濁內阻所致的腹痛、腹瀉等症狀。
  2. 配合其他藥物，增強療效: 大腹皮與藿香、厚朴等藥物搭配，可形成協同作用，增強藥效。例如，大腹皮可促進藿香的發散作用，厚朴則可加強大腹皮的理氣作用，共同達到消暑化濕、理氣健脾的效果。

茯苓

6 / 11

藿香正氣散中加入茯苓，主要基於以下兩方面原因：

  1. 健脾利濕： 茯苓味甘淡，性平，入脾、肺經，具有健脾利溼、滲溼止瀉之效。藿香正氣散主要用於治療暑溼感冒，常伴有脾胃溼困，食慾不振等症狀。茯苓能健脾胃，利水溼，幫助脾胃運化水溼，緩解脾胃不適，配合其他藥物更有效地治療暑溼感冒。
  2. 和中降逆： 茯苓還有利水滲溼，和中降逆的作用，能緩解嘔吐、噁心等症狀，與藿香、佩蘭等藥物協同作用，增強方劑的止嘔降逆功效，更好地緩解暑溼感冒所致的嘔吐、腹瀉等症狀。

厚朴

7 / 11

  2. 調和脾胃：厚朴能理氣和中，調和脾胃功能，有助於改善濕邪停滯所致的脾胃不和、消化不良等問題。藿香正氣散中，厚朴與藿香、蒼朮等藥物協同作用，可增強整體的祛濕止瀉、調和脾胃之效。

  2. 升清降濁： 桔梗具有升清降濁之效，可將濁氣下降，清氣上升，有助於改善脾胃濕濁困阻所致的腹瀉等症狀。同時，桔梗可協助藿香等藥材升發脾胃之陽氣，進而達到扶正祛邪之效。

白芷的加入，使藿香正氣散的功效更加全面，能夠更有效地治療濕熱、寒濕等引起的各種症狀。

藿香正氣散中加入甘草，主要有以下兩個原因：

  1. 調和藥性: 藿香正氣散諸藥性峻，甘草性甘平，可緩和諸藥之燥烈，避免傷胃。甘草能調和藥性，使藥效更為平和，避免副作用。
  2. 增強藥效: 甘草能增強藥物的滲透性，幫助其他藥物更好地發揮功效。同時，甘草亦可緩解脾胃虛弱所致的噁心、嘔吐等症狀，有利於藥物的吸收和發揮作用。

中藥方證辨證推理

一、病因辨證分析

藿香正氣散主要針對的病因是外感風寒，內傷濕滯，以及與此相關的其他因素，如飲食不節等。具體分析如下：

  • 外感風寒： 當人體感受風寒之邪時，衛氣受損，正邪交爭，可出現發熱、惡寒、頭痛等症狀。尤其是在夏季或濕氣重的環境中，毛孔開泄，更容易感受風寒濕邪。
  • 內傷濕滯： 濕邪是導致許多疾病的重要因素。《黃帝內經》中提到：「春傷於風，邪氣留連，乃為洞泄」、「長夏善病洞泄寒中」、「濕盛則濡泄」，強調了濕邪與腹瀉的密切關係。脾臟喜燥惡濕，當濕邪困阻脾胃，影響其運化功能時，就會導致氣機不暢，出現脘腹脹滿、疼痛等症狀。濕邪停滯中焦，還會影響脾胃的升清降濁功能，導致噁心、嘔吐、腸鳴、腹瀉等症狀。
  • 飲食不節： 過食生冷、肥甘厚膩之品，或飲食不規律，損傷脾胃，導致運化失職，也會產生濕邪。濕邪內生，與外感風寒相互影響，加重病情。
  • 四時不正之氣/山嵐瘴氣： 古代醫家認為，在一些特殊環境下，如山林、海島等濕氣較重的地方，存在著「四時不正之氣」或「山嵐瘴氣」，這些都是導致水土不服的重要因素，也與濕邪相關。

二、藿香正氣散的治療原理

藿香正氣散的治療原理是解表化濕，理氣和中。它通過以下幾個方面來達到治療目的：

  1. 解表散寒，祛風勝濕：

    • 藿香： 作為君藥，具有芳香化濕、解表散寒的功效，能祛除體內的濕濁，並解散表面的風寒之邪。
    • 紫蘇葉、白芷： 輔助藿香解表散寒，同時具有芳香化濕的作用，加強祛除體內濕邪的能力。

  2. 理氣和中，健脾燥濕：

    • 陳皮、厚朴、大腹皮： 這三味藥具有理氣寬中、行氣化濕的功效，能消除脘腹脹滿、疼痛等症狀。
    • 白朮、茯苓： 具有健脾益氣、利水滲濕的功效，能增強脾胃的運化功能，從根本上解決濕邪產生的問題。
    • 半夏： 燥濕化痰，和胃止嘔，針對濕邪引起的噁心、嘔吐等症狀。
    • 桔梗： 宣肺利氣，開宣肺氣，使氣機條暢，有助於濕邪的排出。

  3. 調和諸藥：

    • 甘草： 調和諸藥，兼有健脾益氣的作用，使整個方劑的作用更加協調。

三、方中各藥的具體作用

  • 藿香： 芳香化濕，解表散寒，是治療濕濁內阻、外感風寒的要藥。
  • 紫蘇葉： 解表散寒，行氣寬中，用於風寒感冒，兼能解魚蟹毒。
  • 白芷： 解表散寒，祛風止痛，兼能燥濕止帶。
  • 半夏： 燥濕化痰，降逆止嘔，消痞散結。
  • 陳皮： 理氣健脾，燥濕化痰，用於脾胃氣滯。
  • 厚朴： 行氣消積，燥濕除滿，用於脘腹脹滿。
  • 大腹皮： 行氣導滯，利水消腫，用於腹脹便秘，水腫。
  • 茯苓： 健脾滲濕，寧心安神，用於脾虛濕盛。
  • 白朮： 健脾益氣，燥濕利水，止汗，安胎。
  • 桔梗： 開宣肺氣，祛痰排膿，利咽散結。
  • 甘草： 益氣補中，調和諸藥，緩急止痛，清熱解毒。

總結：

藿香正氣散通過辛溫發散以解表散寒，芳香化濕以祛除濕邪，理氣和中以調理脾胃，從而達到治療外感風寒、內傷濕滯引起的各種症狀的目的。它不僅能緩解發熱、惡寒、頭痛等表證，還能改善脘腹脹滿、噁心嘔吐、腹瀉等裡證，適用於多種與濕邪相關的疾病。

此外，從現代藥理學的角度來看，藿香正氣散具有健胃、鎮吐、緩解胃腸平滑肌痙攣、調整胃腸功能、抗菌、抑制流感病毒、解熱、利尿、祛痰等多種作用，進一步驗證了其在中醫理論指導下的臨床療效。

方劑介紹

藿香正氣散的主要功效是「解表化濕，理氣和中」，專門改善因為外感風寒，內傷濕滯所造成的霍亂(腸胃炎)、上有嘔吐、下有腹瀉。發燒、怕冷、頭痛、肚子痛，以舌苔白膩為主，亦可用於山嵐瘴癘等證。

此中藥在古代，尤其是針對人們因為爬山涉水，通過山林間遇到各種「山嵐瘴氣」，因為「四時不正之氣」所導致的各種水土不服的症狀，最適合運用此方加以改善。尤其是住在海島地區、山區的人環境濕氣重，更需要此方劑。

藿香正氣散治的那種上吐下瀉，通常是因為兩個原因同時出現：一是外面受了風寒（比如著涼、吹冷風），二是身體裡面本來就濕氣太重。

古書上講，風邪和濕邪都能讓人拉肚子，尤其是濕氣特別重的時候，更容易讓腸胃功能亂掉，出現又吐又拉。

如果風寒堵在身體表面，就會讓皮膚的「衛氣」沒法正常工作，身體里的正氣和邪氣互相打架，所以人會怕冷、發燒。風寒如果影響到後腦勺和脖子附近的經絡（太陽經），經氣運行不順，就會頭痛。

人體的脾胃是負責消化食物、分清吸收和向下排出的重要器官。脾喜歡乾燥，最怕濕氣。

如果濕氣困住了脾胃，脾的運化功能就受影響，氣機也不通暢，所以會覺得肚子脹、悶、疼。脾本來應該把營養精華往上送，胃本來應該把食物殘渣往下排。

如果濕氣堵在肚子中間，讓上下的運行亂掉，該清的清不了、該濁的濁不下去，就會出現惡心、嘔吐、肚子里咕嚕咕嚕響、拉肚子。

所以古人常說「濕多成五瀉」及「無濕不成瀉」的說法，就是強調濕氣是造成吐瀉的關鍵因素。

另外，風寒如果從體表影響到肺和皮膚這一層，也可能連累脾胃，讓腸胃升降功能失調，導致嘔吐、腹瀉。

不過這種病通常不是單純的風寒引起的，而是風寒和濕氣攪在一起，才會出現明顯的上吐下瀉。

飲食不注意也是重要原因。比如吃太多油膩厚味的東西，讓體內生出濕熱；或者吃了生冷、不乾淨的食物，傷了脾胃，都會讓脾胃消化功能失常。食物里的營養吸收不了，反而變成濕氣堵在體內，最後就可能嘔吐、拉肚子。

因此，藿香正氣散主要改善的疾病，病位主要在脾胃和大腸、小腸，最核心的問題是「濕氣」。外面有風寒束表，裡面有濕濁堵在肚子中間，導致脾胃升降失常、清濁不分，所以就出現了怕冷發燒、頭痛、肚子脹滿、惡心嘔吐、腸鳴腹瀉這些症狀。

如果用一個現代人能秒懂的比喻，來拆解藿香正氣散的組成，可以想象人體的腸胃像一條因為「濕氣+寒氣」而堵車、打滑、冒臭水的城市主幹道，而藿香正氣散就是一支緊急出動的道路搶修+環境清理+交通指揮聯合小隊。

1.藿香:總指揮+強力除濕機

藿香它是整個隊伍的靈魂。像一台大功率的抽濕機，同時又是現場總指揮，專門對付中焦（胃和腸道）里積攢的濕氣和濁氣，還能把困在體表的風寒趕出去。哪裡有嘔吐、腹瀉、肚子悶脹，它第一個衝上去。

2.紫蘇 + 白芷:體表防風保暖組

像給身體裹上一條熱毛巾，再加一杯熱薑茶。它們負責把停留在皮膚表面的風寒「推出去」，幫你緩解怕冷、發燒、頭痛。紫蘇還有一股香氣，能幫著化濕；白芷則能止頭痛、通鼻子。

3. 茯苓+ 白朮：抽水機+防水地基

茯苓像一台安靜的水泵，把腸道里多餘的濕水抽走，從小便排出。白朮則像加固地基的防水層，讓脾胃不再滲水，恢復正常的吸水運化能力。兩者配合，讓「濕」無處可存。

4. 半夏曲 + 陳皮：止嘔+排氣閥

半夏曲專門對付「往上冒」的惡心嘔吐，像把一個翻騰的鍋蓋按下去，還能把黏膩的濕痰化掉。陳皮像廚房裡的排風扇+管道疏通劑，理氣、排氣，讓肚子不再脹得難受。

5. 厚朴+ 大腹皮：腸道疏通工

厚朴像一把寬大的鏟子，把堵在中焦（胃和腸）的濕氣、積食、脹氣往下推。大腹皮則更像一個經驗豐富的下水道疏通師傅，專門消除肚子脹滿、腸鳴、腹瀉，讓該往下走的東西順利下行。

6. 桔梗：升降電梯操作員

桔梗在這裡的作用很特別，它像一部向上的電梯，把脾氣（清氣）往上送，防止脾氣下陷導致的腹瀉；同時又能開肺氣，幫助體表排寒。和厚朴、大腹皮一升一降，恢復腸胃的正常秩序。

7. 炙甘草：後勤協調員+緩和劑

甘草像後方的總務，負責緩和所有藥物的衝突，讓它們不急不躁地工作，同時補一點脾氣，保護胃黏膜，最後還能調和味道，讓藥不那麼難喝。

此方由藿香帶隊，先抽濕、再驅寒；紫蘇白芷守住體表；茯苓白術排掉水路積水；半夏陳皮止嘔理氣；厚朴大腹皮打通腸道堵塞；桔梗升降有序；甘草全場協調。最後你的腸胃從「濕寒泥石流路段」變回「通暢乾淨的雙向四車道」。

此方的功效與「平胃散」類似，都能治療「濕邪困阻中焦」的病證。而平胃散以蒼朮為主藥，具有燥濕運脾，行氣和胃之作用，其燥濕和胃的作用比較強，主要是用以改善臟腑病。後人將此方加上蒼朮，稱為「藿香養胃湯」。

藿香正氣散以辛溫芳香的藿香為主藥，具有外散風寒，內化濕濁，理氣和中之功效，主治外有風寒、內有濕滯之證，主治外感＋濕氣之證。

與藿香正氣散類似的「正氣散」中藥很多，例如「不換金正氣散」。藿香正氣散與「香薷散」主要都是用來治療夏季喝冷飲，外感風寒，內傷濕氣過重之證。

後人以此方加減變化，產生了很大的發展。例如《溫病條辨》就有5種加減正氣散，就是以此方為加減變化。後人也有改成丸劑、膠囊或是藿香正氣水，應用層面極廣。

藿香正氣散可健胃，鎮吐，緩解胃腸平滑肌痙攣，調整胃腸功能，抗菌，抑制流感病毒，解熱，利尿，祛痰。用於胃腸型感冒、急性胃腸炎、中暑、嘔吐、急慢性腎炎、霍亂吐瀉、不服水土、小兒食傷、夏天感冒。 酒精中毒(喝太多酒)造成的現象，也可以運用藿香正氣散緩解。

  • 呼吸系統與外感疾病：感冒挾濕（暑濕外感、夏季小兒濕邪困脾吐瀉）、 新型冠狀病毒肺炎（伴胃腸道症狀或以消化道為首發症狀）、 寒哮、 咳嗽變異型哮喘、 外感高熱、 濕溫病。
  • 神經與精神系統疾病：中樞性呃逆、 頑固性頭痛、 梅尼埃病（眩暈、濕濁眩暈）、 失眠（慢性失眠）、 分離轉換障礙
  •  皮膚與免疫系統疾病：痤瘡（脾虛夾濕型）、 濕疹、 結節性癢疹、 蕁麻疹、 小兒皮疹、 肛門潮濕症
  • 心血管與全身性疾病/症狀：冠心病心絞痛、 水腫、 中暑（急性中暑、暑濕）、 酒精中毒、 酸中毒、 大棚綜合徵、 運輸應激綜合徵（主要指動物）
  • 五官科疾病：鼻淵
  • 肝膽與婦科疾病：慢性乙型肝炎（肝病泄瀉）、 妊娠惡阻
  • 獸醫臨床疾病：耕牛寒濕泄瀉（牛急性腸胃炎）、 幼豬冷瀉（斷奶仔豬腹瀉病）、 番鴨水瀉、 牛肉傷外感症、 犬胃寒嘔吐、 豬牛暑濕泄瀉

 

 

傳統服藥法

【組成】大腹皮、白芷、紫蘇、茯苓（去皮）各一兩（各30g）；半夏曲、白朮、陳皮（去白）、厚朴（去粗皮，姜汁炙）、苦桔梗各二兩（各60g）；藿香（去土）三兩（90g）；炙甘草二兩半（75g）。

【用法】上藥研為細末。每服二錢（6g），水一盞，加生薑三片、大棗一枚，同煎至七分，熱服。若欲取汗，可覆衣被，再煎服。現代用法：共研細末，每服9g，以姜、棗煎湯送服；亦可作湯劑，水煎服，用量按原方比例酌定。

注意事項及副作用

  • 此方溫燥，風熱或陰虛火旺慎用
  • 有高血壓、心臟病、肝病、糖尿病、腎病等慢性病嚴重者慎用
  • 孕婦、小兒、老年體虛者應在醫師指導下服用 但本方藥偏溫燥，故對風寒襲表，濕滯脾胃，以及山嵐瘴氣所導致的病證，甚為合適。若屬於「陽暑」不適合，「陰屬」適合
  • 「熱重於濕」，不合適，應避免。「濕重於熱」，謹慎、配伍後可用。

現代藥理研究

  1. 調節胃腸平滑肌運動：藿香正氣水對豚鼠、兔離體十二指腸的自發性收縮及對組胺、Ach、氯化鋇所致的回腸痙攣性收縮均有良好解痙作用，呈一定的量效關係。
  2. 對胃腸功能具有雙向調節作用：對正常小鼠胃排空和腸推進有不同程度的促進作用，但可不同程度地拮抗阿托品所致胃腸功能抑制及新斯的明所致功能亢進。藿香正氣液有促胃腸動力作用，該作用可能與其對MTL的影響有關。對藿香正氣水組方的正交分析結果發現，該方中僅藿香、厚朴、陳皮、蒼術、半夏對組胺誘導的豚鼠離體回腸痙攣有解痙作用，尤以陳皮作用最強，以白芷、紫蘇、厚朴、半夏、陳皮、蒼術6味藥配伍的復方解痙作用最強，與原方作用相當。採用均勻設計和藥效學相結合的方法，以家兔離體十二指腸的抑制率為考察指標，經研究形成減味藿香正氣水，從原來的11味降低到5味，最佳配比是:厚朴7.82g，陳皮3g，蒼術3g，半夏3g，廣藿香油30μL。廣藿香油、厚朴酚為藿香正氣水作用於腸道的藥效物質基礎。藿香正氣水能夠抑制由膽鹼受體激動劑——卡巴膽鹼(carbachol，CCH)和KCl引起的大鼠結腸平滑肌收縮，其抑制收縮的作用與抑制SMC膜上鈣通道的開放相關。藿香正氣水對腸道分泌的影響主要和氯離子通道有關。
  3. 止瀉、鎮吐：藿香正氣丸、水、顆粒劑、衝劑等，均能明顯抑制小鼠小腸推進運動。藿香正氣軟膠囊對番瀉葉所致小鼠腹瀉有明顯抑制作用。採用番瀉葉煎液加寒冷刺激灌胃複製大鼠急性腹瀉模型，藿香正氣散能調節急性腹瀉大鼠水、電解質平衡，降低血漿cAMP水平，對腸黏膜有保護作用。藿香正氣提取物對腹瀉型腸易激綜合徵模型大鼠腸動力紊亂具有調節作用。藿香正氣提取物可降低D-IBS模型大鼠小腸推進率，減弱結腸轉運效應，提高大鼠血清NO含量，降低5-HT濃度，減少EC數量。藿香正氣液可明顯改善濕阻證大鼠腹瀉症狀，改善胃腸黏膜充血水腫、胃黏膜出血點及血塊等症狀，其機制可能與提高回腸黏膜緊密連接蛋白-1的表達有關。藿香正氣軟膠囊還有止嘔作用，可以延長家鴿嘔吐的潛伏期，減少嘔吐次數。此外，顆粒劑及丸劑亦有類似的止吐作用。
  4. 解熱：對傷寒菌苗所致的家兔發熱，藿香正氣丸及顆粒劑均有明顯解熱作用。藿香正氣水對醋酸刺激腸管漿膜或腸系膜引起的內臟軀體反射性疼痛有明顯鎮痛作用。藿香正氣膠囊對酒石酸銻鉀的致痛有對抗作用;藿香正氣口服液灌胃小鼠能顯著提高熱板法試驗的痛閾值。
  5. 抗病原微生物：藿香正氣水體外對藤黃八疊球菌、金黃色葡萄球菌、痢疾桿菌、沙門菌、甲乙型副傷寒桿菌等有明顯抑菌作用，尤其對藤黃八疊球菌、金黃色葡萄球菌作用較強，並對紅色毛癬菌、石膏樣毛癬菌、絮狀表皮癬菌、石膏樣小孢子菌、白色念珠菌、新生隱 球菌及皮炎芽生菌等有明顯抑菌作用。藿香正氣顆粒劑對A1、A3及B 型流感病毒也有抑制作用。
  6. 調節免疫：藿香正氣丸能提高小鼠外周血淋巴細胞3H-TdR摻入量。體外實驗證實，藿香正氣水能抑制大鼠被動變態反應，穩定肥大細胞膜，有抗過敏作用。藿香正氣散能改善濕困脾胃型亞健康模型大鼠一般體徵，增加自發活動次數，增加脾臟、胸腺臟器系數，增加血清糖、蛋白、脂類含量，降低血清K+、Na+、Cl-含量，降低血清IL-6的含量，增加血清IgG含量。藿香正氣散能改善模型動物的免疫及代謝功能，這可能是防治濕困脾胃型亞健康的作用機制之一。

藿香正氣散的經絡型態

藿香正氣散最適合「寒性陽虛經絡體質」的人，一般人到了夏季之後，體內的陽經能量會增強，實證屬於常態。

然而，有一定比例的人，儘管到了夏天，還是出現手三陽經虛證，這種現象在陰雨天氣中會更加明顯，這就是腹中寒濕的典型經絡現象。

這時候運用溫中、去濕中藥就很適合，如果又有外感症狀時，比對症狀就有很高的機率可以運用藿香正氣散。

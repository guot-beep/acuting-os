方劑組成解釋

茜草根

1 / 5

失笑散是一種中藥方劑，其主要功效是用於舒緩情緒，疏通肝氣，改善因情緒不佳引起的各種身體不適。茜草根（學名：Rubia cordifolia）在此方中的加入，主要是因為其具有清熱解毒、促進血液循環的功效。

茜草根含有多種活性成分，如萜類和醌類化合物，這些成分可以促進血流，減少鬱結，並且有助於肝臟的健康。失笑散所針對的情緒問題常常與肝氣不舒有關，而茜草根能有效疏通肝經，故在方劑中加入茜草根，可以達到調理情緒、消除憂鬱的效果。

此外，茜草根還具清熱解毒的功能，能夠改善因熱毒而引起的各種症狀，增強藥效的整體平衡。因此，在失笑散中選用茜草根，是為了增強其疏肝解鬱及調和全身氣血的綜合效果。

益母草

2 / 5

失笑散是一種常見的中藥方劑，主要用於調理情緒、緩解焦慮與抑鬱等症狀。在其組成中，益母草的加入具有重要的意義。益母草，其性味苦、辛、微寒，歸肝、心、膀胱經，具有活血調經、清熱解毒的功效。

首先，益母草能夠促進血液循環，改善血瘀的情況，從而有助於緩解情緒問題。情緒低落、有時與氣血運行不暢有關，益母草的活血作用可以改善這種情況，使人心情變得愉快。

其次，益母草也有助於清心火，平肝解鬱。在中醫理論中，情緒的波動往往與肝鬱有關，益母草能夠調節肝氣，達到疏通的效果，從而減輕焦慮和抑鬱的 symptoms。

因此，益母草在失笑散中的使用，不僅增強了方劑的整體療效，而且有助於恢復患者的情緒平衡與心理健康。

血餘炭

3 / 5

失笑散是一種中藥方劑，主要用於治療情志所致的病症，如焦慮、抑鬱等情緒障礙。在其組成中，血餘炭的加入具有重要的臨牀意義。血餘炭是由處理過的動物血液製成的炭粉，其性質燥熱，具有止血、清熱、解毒的功能。

失笑散中的血餘炭，通過清理體內的寒熱失調，幫助調和氣血，促進身心的和諧。首先，血餘炭能夠吸附體內的濕氣與熱邪，有助於緩解因情志抑鬱而引起的煩悶情緒。其次，血餘炭還能整體提升陰陽的平衡，有助於改善情緒波動。最後，失笑散整體強調對心理和生理雙重調理，而血餘炭的作用正好契合這一需求，可謂是失笑散中不可或缺的成分之一。因此，血餘炭的加入不僅提升了方劑的療效，也增強了其針對情志相關疾病的治療效果。

  2. 疏肝解鬱，調和氣血：蒲黃還具有疏肝解鬱的功效，有助於舒緩情緒，調節氣血運行。失笑散方中，蒲黃可與其他藥材協同作用，達到疏肝解鬱、調和氣血的目的，從而改善患者的失笑症狀。

中藥方證辨證推理

失笑散：從病因辨證角度分析

失笑散，顧名思義，意為止痛效果迅速，令人疼痛消除，不禁失笑。要理解其治療原理，需從中醫病因辨證角度入手，分析方中藥物如何針對病因，達到活血化瘀、理氣止痛的目的。

一、病因辨證分析：

失笑散主要針對的病因是血瘀，可以概括為以下幾個方面：

  • 內傷七情（以怒、憂、思為主）： 情志不舒，肝氣鬱結，容易導致氣滯血瘀。肝主疏泄，氣機不暢則血行受阻，久而久之形成瘀血。例如，婦女經期或產後，情緒波動較大，更容易導致氣滯血瘀，進而引起痛經、產後腹痛等。
  • 外感六淫（以寒、濕為主）： 寒邪凝滯收引，容易導致血脈不通，產生瘀血。濕邪黏膩重濁，阻礙氣機運行，也容易導致血瘀。例如，寒凝血瘀引起的痛經，或跌打損傷後局部受寒濕侵襲導致的瘀血腫痛。
  • 飲食不節： 過食生冷、肥甘厚味，損傷脾胃，導致氣血生化不足，或痰濕內生，阻礙氣機運行，也會間接導致血瘀。
  • 勞逸失度： 過勞則氣血耗損，過逸則氣血運行緩慢，都容易導致氣血運行不暢，產生瘀血。
  • 其他因素（外傷、手術等）： 外傷或手術直接損傷血脈，導致局部瘀血。

綜上所述，失笑散針對的病因多種多樣，但最終都歸結為氣血瘀滯。氣為血之帥，血為氣之母，氣滯則血瘀，血瘀則氣滞，二者相互影響，形成惡性循環，導致疼痛等各種症狀。

二、藥物組成及治療原理：

失笑散的精妙之處在於其藥物組成簡潔，但配伍精當，直擊血瘀病機，達到活血化瘀、理氣止痛的目的。以下逐一分析：

  • 五靈脂： 味苦、甘，性溫。入肝、脾經。主要功效為活血止痛，化瘀消癥。 五靈脂是鼯鼠的乾燥糞便，其性質溫行，具有很強的活血化瘀之力。《本草綱目》記載其能“散血氣，止心痛，散血塊，消瘕痞”。
  • 蒲黃： 味甘、辛，性平。入肝、心、脾經。主要功效為止血，化瘀，利尿。 蒲黃既能止血，又能化瘀，其止���作用是通過活血化瘀來實現的，所謂“止血不留瘀”。同時，蒲黃還具有利尿的作用，可以幫助排除體內瘀血產生的代謝廢物。

方義解析：

  1. 活血化瘀，通則不痛： 失笑散的核心治療原理是活血化瘀。五靈脂辛溫走竄，能快速活血化瘀，消散血塊；蒲黃既能止血又能化瘀，可促進血液循環，消除瘀血。二藥合用，活血化瘀之力倍增，使瘀血得化，氣血流通，疼痛自然緩解。
  2. 氣血兼顧，行氣止痛： 中醫認為“不通則痛”，氣血瘀滯是導致疼痛的主要原因。失笑散不僅活血化瘀，還兼顧行氣。五靈脂辛散溫通，能行氣止痛，蒲黃活血化瘀，促進氣機運行。氣行則血行，氣血流通，疼痛自然消除。
  3. 針對婦科，調經止痛： 失笑散尤其擅長治療婦科瘀血病症，如產後惡露不盡、痛經等。產後或經期，血瘀是常見的病理狀態。失笑散活血化瘀，能促進瘀血排出，使胞宮氣血通暢，从而缓解疼痛。
  4. 佐以醋制，增强疗效： 古方常以醋调服，醋味酸涩，具有收敛固涩，活血化瘀的功效。醋能够引药入肝经，增加活血化瘀的效果，并能缓解五灵脂的燥性。

三、總結：

失笑散的治療原理是基於中醫病因辨證的基礎上，針對血瘀病機，運用五靈脂和蒲黃兩味藥物，配伍精當，以活血化瘀、理氣止痛為主要功效，廣泛應用於治療各種氣血瘀滯所致的疼痛，尤其擅長治療婦科瘀血病症。 其藥簡力專，療效迅速，故被譽為“失笑散”。

總之，理解失笑散的治療原理，不僅要掌握方中藥物的功效，更要從中醫病因辨證的角度，分析其針對的病因和病機，才能更深刻地理解其臨床應用價值。 雖然此方疗效显著，但属于较为峻烈的活血化瘀剂，应在中医师指导下使用，不可自行滥用。

主治功效

失笑散主治功效分析

方劑組成

  • 五靈脂：活血止痛，化瘀消癥。
  • 蒲黃：止血，化瘀，利尿。

古代記載主治

綜合多部古醫籍的記載，失笑散主要用於治療以下病症：

  • 氣血瘀滯諸痛： 心腹刺痛、胃脘痛、脅肋痛、少腹痛、腰痛、當臍㽲痛，以及跌打損傷導致的疼痛。
  • 婦科疾病： 產後惡露不盡、兒枕痛（胎盤殘留或子宮收縮不良）、血暈、經行腹痛、痛經、血瘀經閉、崩漏（血崩經溢）等。
  • 小腸氣痛： 男子小腸疝氣疼痛。
  • 跌打損傷： 血攻心。
  • 牙痛： 風蟲牙痛（神仙失笑散）。
  • 其他： 目中生翳往來不定、血瘀導致的大便閉結、血瘀下焦等。

治療原理

失笑散的治療原理主要基於中醫的“活血化瘀”和“理氣止痛”理論。

  1. 活血化瘀：

    • 五靈脂 和 蒲黃 均為活血化瘀的要藥。五靈脂長於行血止痛，化瘀消癥；蒲黃既能止血又能化瘀，還能利尿。二藥合用，活血化瘀之力更強。
    • 古文記載中多次提及失笑散用於治療“血瘀”、“血結”、“血滯”、“血氣痛”等病症，說明其主要功效在於化除體內瘀血。
    • 《血證論》指出蒲黃“行水則氣行，氣止則血止”，靈脂“氣味溫行以行血”，二藥合用，大能行血。
    • 《類證治裁》中多次提到失笑散用於“理絡”、“破血中氣滯”、“消瘀”，進一步說明其活血通絡的作用。

  2. 理氣止痛：

    • 中醫認為“不通則痛”，氣血瘀滯是導致疼痛的主要原因之一。失笑散通過活血化瘀，使氣血流通，從而達到止痛的目的。
    • 《本經逢原》指出失笑散“入肝散血最速”，《類證治裁》中也有“血分氣滯，遂用失笑散，一服痛除”的醫案，說明失笑散能疏肝理氣，通絡止痛。
    • 《衛生寶鑒》指出失笑散能“定心氣痛不可忍”，《太平惠民和劑局方》中記載失笑散“治產後心腹痛……百藥不效，服此頓愈”，都表明失笑散止痛效果顯著。

  3. 針對婦科疾病：

    • 產後惡露不盡、兒枕痛、血暈等婦科疾病，多與產後瘀血阻滯胞宮有關。失笑散活血化瘀，能促進瘀血排出，使胞宮恢復正常，故可治療此類疾病。
    • 《類證治裁》提到“產後惡露，失笑散”、“手摸臍腹成塊者，兒枕未消也，失笑散”，《血證論》指出“產後瘀血，身痛，腰痛……宜歸芎失笑散”，都說明失笑散在婦科疾病中的廣泛應用。

  4. 醋制增效：

    • 多部古籍，如《衛生寶鑒》、《蘇沈良方》、《太平惠民和劑局方》，均提到失笑散需要用醋調製或熬膏，再入水煎服。醋本身具有活血散瘀、消食化積的作用，與失笑散合用，能增強其活血化瘀、止痛的效果。

總結

失笑散作為一首經典的活血化瘀方劑，以五靈脂和蒲黃為主要成分，通過活血化瘀、理氣止痛，廣泛應用於治療各種氣血瘀滯所致的疼痛，尤其擅長治療婦科瘀血病症。其療效顯著，被譽為“近世神方”。

傳統服藥法

蓽茇8分，細辛（淨葉）1錢，大冰片2分5釐。上為極細末。
擦牙痛處。伏於桌邊流涎，片時見效，便能飲食。

注意事項及副作用

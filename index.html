Patient Record System

我的病歷系統 / Clinical Charting

這一區是你未來臨床每天會用的入口：先用去識別化 patient code 建病例，再用 SOAP note 追蹤每次治療、用針、方藥、頻率、變化與保險文件需要的紀錄。

私用病例資料
CH 新增病例 建立 patient code、主訴、西醫診斷、中醫病名、辨證與治療目標。 SO 新增 SOAP 每次看診記錄 S/O/A/P、用穴、手法、方藥、西藥、療效與下次計畫。 TR 療程追蹤 追蹤疼痛量表、週期、睡眠、情緒、消化、不孕療程節點與客觀變化。 BI 保險紀錄準備 保留 coding-ready documentation 概念：診斷、醫療必要性、治療內容與反應。
病歷安全原則 目前請只輸入去識別化資料：patient code，不放完整姓名、完整生日、電話、地址、保險號碼或任何可直接辨識身分的資訊。

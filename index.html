Patient Record System

我的病歷系統 / Clinical Charting

這一區是你未來臨床每天會用的入口：先用去識別化 patient code 建病例，再用 SOAP note 追蹤每次治療、用針、方藥、頻率、變化與保險文件需要的紀錄。

私用病例資料
CH 新增病例 建立 patient code、主訴、西醫診斷、中醫病名、辨證與治療目標。 SO 新增 SOAP 每次看診記錄 S/O/A/P、用穴、手法、方藥、西藥、療效與下次計畫。 TR 療程追蹤 追蹤疼痛量表、週期、睡眠、情緒、消化、不孕療程節點與客觀變化。 BI 保險紀錄準備 保留 coding-ready documentation 概念：診斷、醫療必要性、治療內容與反應。
病歷安全原則 目前請只輸入去識別化資料：patient code，不放完整姓名、完整生日、電話、地址、保險號碼或任何可直接辨識身分的資訊。

Formulas

方劑資料庫 / Herbal Formulas

方名、組成、功效、主治證型、加減與禁忌，依分類瀏覽或直接搜尋。

Materia Medica

中藥 / Single Herbs

性味歸經、功效、主治、安全與相關方劑，依分類瀏覽或直接搜尋。

Pharmacology

西藥 / Pharmacology

作用機轉、作用部位、適應症、禁忌與考試重點。禁忌與交互作用一律引用官方標籤，課件沒有的欄位留空不補。

Symptoms

症狀 / Symptoms

病人怎麼講、要問哪幾個面向、同一個症狀怎麼分證型。問診面向附「為什麼要問」，鑑別欄連到證型卡。

Differentiation

辨證鑑別 / Pattern Comparisons

相似證型並排對照：病機、舌脈、鑑別要點。TCM 病理與 Advanced Therapeutics 的對照表都收在這裡。

Conditions

中西醫病症對照 / Conditions

西醫病名 × 傳統病名 × TCM 證型，中英標籤互相關聯，連向常用穴位、方劑與安全旗標。

Graph rule 西醫診斷、傳統病名、證型不是一對一翻譯；AcuTing 用 relation records 表示「可能相關」，每次病例仍要依實際 SOAP 與臨床辨證判斷。

Sources

資料來源 / Bilingual References

每筆穴位資料會逐步標註英文與中文來源；正式定位仍以 WHO/教材為核心，網路資料作快速查找、翻譯對照與欄位補強。

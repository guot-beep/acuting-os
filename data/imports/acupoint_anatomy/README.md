# Acupoint Anatomy and Safety Staging

This directory contains review-only, source-traceable anatomy and safety
signals for standard acupuncture points.

Rules:

- Never write directly from this directory to `data/acupoints/361.json`.
- A study cohort or imaging set is not a complete anatomy description for
  every included point.
- Only point-specific structures explicitly named by a source may appear as
  candidates for `nerves`, `vessels`, or other canonical anatomy fields.
- MRI- or ultrasound-measured distances are population observations, not a
  universal safe needling depth. Body size, angle, direction, and individual
  anatomy remain review factors.
- All records stay `draft` until a qualified reviewer checks the cited source.
- These records are study and safety review prompts, not medical advice.

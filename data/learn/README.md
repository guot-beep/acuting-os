# AcuTing Learn Public Content Layer

This layer is for a future public-facing English educational site. It can use existing Chinese TCM websites as structural inspiration, but content should be rewritten, translated, and cross-checked against English professional sources before publication.

## Separation

- `AcuTing OS`: private clinical notebook, SOAP notes, cases, billing training, personal study.
- `AcuTing Learn`: public bilingual or English-facing educational site, no patient data.

## Content Architecture

Inspired by simple public TCM archive structures:

- Acupuncture
- Auricular
- Herbs
- Formulas
- Conditions
- Western Medications
- Herb-Drug / East-West Interactions
- Learning / NCCAOM
- Clinic Education Articles

## Content Rule

Do not copy articles wholesale. Build each page from:

1. Extracted topic and field structure.
2. Original Chinese note or public-domain/permission-safe facts.
3. English rewrite.
4. Authority cross-check.
5. Source citations.
6. Safety and disclaimer section.

## Recommended Page Pattern

Each public article should have:

- Title English
- Title Chinese
- Short plain-English summary
- TCM perspective
- Biomedical perspective when relevant
- Common patterns
- Acupuncture / auricular / formula links
- Contraindications and referral red flags
- Evidence/source notes
- Last reviewed date

## Source Priority

- WHO-style acupuncture nomenclature and point-location standards for point identity/location.
- NCCAOM outline for exam relevance.
- NCCIH/NIH and other professional English sources for patient-facing safety language.
- Evidence-based acupuncture summaries and peer-reviewed research for condition claims.
- Anatomy sources for English anatomical terminology.

This layer should support future clinic branding, but it must be conservative, educational, and source-aware.

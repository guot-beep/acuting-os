# 陽蹺脈

## 基本資料

- 經絡：陽蹺脈
- 出自：《靈樞·寒熱病》
- 核心功能：司目之開合，主肢體運動，用於目痛、不寐及肢體經脈出現陰緩陽急的病症。
- 位置：起於足跟外側，下經外踝上行腓骨後緣，沿股部外側和脅後上肩，過頸部上夾口角進入目內眥。
- 起止穴：起於申脈，止於睛明。
- 所屬經穴：共12穴

# 循行

## 循行路線

### 《經絡腧穴學》

起於跟中，出足太陽之申脈，循外踝上行，沿髀脅上肩，循面，交目內眥，會睛明，入腦，下耳後，入風池。

陽蹺脈，起於足跟外側，出足太陽經的申脈，經外踝上行腓骨後緣，沿股部外側和脅後上肩，過頸部上夾口角，進入目內眥，與陰蹺脈相會合於睛明，再沿足太陽膀胱經上額，下耳後與足少陽經合於風池。

## 歌訣

陽蹺脈起於跟中，  
上合三陽外踝行，  
從脅循肩入頸頄，  
屬目內眥太陽經。

# 應用

## 主治

痛、不寐及肢體經脈出現陰緩陽急的病症。

## 詳解

陰蹺脈氣失調，會出現肢體外側的肌肉緩而內側拘急，陽蹺脈氣失調，會出現肢體內側肌肉弛緩而外側拘急的病症。這說明蹺脈與下肢運動功能有密切關係。

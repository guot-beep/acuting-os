# curriculum/cases/ — 病例討論 / 臨床見習 / 跟診紀錄

**收什麼:** 具體某一個人的病例 —— 課堂病例討論、跟診紀錄、見習報告、
老師示範的醫案、經典醫案(葉天士、張錫純那種)。

**不收什麼:** 教科書式的「不寐怎麼治」→ `conditions/`。分界線是
**有沒有一個具體的人**:有主訴、有舌脈、有這一次的處置 → 這裡。

## 去識別化(放進來之前做)

學校病例課件常留著姓名、生日、就診日期、病歷號。拿掉。
**留下辨證會用到的**:年齡層、性別、職業(如果相關)、季節/地域。

```
case_不寐_60F_更年期.md            ✅
case_腰痛_45M_久坐_2026春跟診.md    ✅
case_王X明_2026-03-14_病歷2288.md   ❌
```

repo 是私有的,但去識別化是為了你之後可以放心把某個病例當教材、貼給其他 AI 讀、
或哪天寫進 AcuTing.com 的文章。

## 一個病例值得記下來的最小結構

不用寫完整 SOAP,課堂病例常常資訊不全 —— **有多少寫多少,缺的就標「課件未提供」,
不要補**(補出來的病例是假的,比沒有更糟)。

```md
# 不寐 60F 更年期
- 主訴 / 病程:
- 望聞問切:舌 / 脈 /
- 辨證:
- 治法:
- 處方:            → 連方劑卡
- 選穴:            → 連穴位卡
- 療效 / 追蹤:
- 老師的重點提醒:   ← 最有價值的一行,別漏
- 我的疑問:        ← 留著,以後回頭看
```

`cases/` 餵養 App 裡的**病例庫**,也回頭當 `conditions/` 病證卡的臨床實例 ——
一個病證卡如果掛得上兩三個真實病例,它就從背誦變成能用的東西。

## 分資料夾
照**哪一輪跟診**分,不照病名(病名靠搜尋找,時間才是你回憶得起來的線索):

```
cases/2026-spring-clinic/
cases/classic/          ← 經典醫案
```

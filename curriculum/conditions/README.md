# curriculum/conditions/ — 病證課件(中西醫結合)

**收什麼:** 以「病」為主題的課 —— 病因病機、辨證分型、治法治則、代表方、
選穴思路、中西醫病名對照、預後與轉歸。內科、婦科、兒科、骨傷、皮膚、五官、
神志都放這裡。

**不收什麼:** 具體某個病人 → `cases/`。單味藥或單個穴的講義 → `herbs/` /
`acupoints/`,即使那堂課是在講某個病的時候教的。

## 為什麼這個資料夾最重要

BLUEPRINT 的臨床 North Star 是:**中藥與西藥的交互作用安全 → 針灸減少副作用 →
處理主要症狀 → 治本/調理體質**。這條線是**病證卡**在承載的,不是中藥卡也不是
穴位卡 —— 那兩個是零件,病證卡才是把零件組起來的地方。所以這裡的課件品質,
直接決定 AcuTing OS 最後好不好用。

一份好的病證課件,填進病證卡會長成:

| 卡片區塊 | 課件裡對應的東西 |
|---|---|
| 中西醫病名對照 | 「不寐 / Insomnia (ICD F51.0)」 |
| 病因病機 | 課件的病機圖或條列 |
| 辨證分型 | 每一型的主證、舌脈 |
| 治法 + 代表方 | 「清心安神,黃連阿膠湯」→ 連到方劑卡 |
| 選穴 | 「神門、三陰交、安眠」→ 連到穴位卡 |
| 西醫視角 | 鑑別診斷、red flag、常見用藥 → 連到 `western/` |
| 飲食作息 | 宜忌 → 連到 `lifestyle/` |

## 檔名
`不寐_insomnia_內科.pdf`、`痛經_dysmenorrhea_婦科.md` —— 中文病名 + 英文 + 科別。
中英都寫,因為 board 考英文、你查資料查中文。

超過約 30 檔再依科別開子資料夾(`內科/` `婦科/` …),現在攤平就好。

# 4. Critical canonical rules

1. Formula wording is evidence, not ontology authority.
2. Biomedical condition context must never define Pattern identity.
3. TCM disease context (`Bi`, `Wei`, `Lin`, menstrual/pregnancy/postpartum states, etc.) must remain distinct from Pattern identity.
4. Cross-system overlap is not an alias.
5. Do not create one Pattern per `X with Y` formula phrase.
6. Prefer graph composition when stable component nodes already exist.
7. Preserve source disagreements and field-level provenance.
8. Do not overwrite accepted V1 values just because a new source is more detailed.
9. Resolve all formula/point/channel IDs against the live canonical registries before production writes.
10. Do not invent missing clinical details.

# 0. Purpose

The previous batches started from Pattern concepts and attached formulas.

This batch runs the logic in the opposite direction:

```text
formula corpus
    ↓
source syndrome wording
    ↓
normalized Pattern concept
    ↓
formula-support density
    ↓
canonical review priority
```

This is useful because a Pattern appearing repeatedly across independent board/course/formula sources deserves earlier review than a phrase appearing once on one formula page.

# 2. Counting rule

The counts below are **minimum confirmed formula anchors**, not guaranteed exhaustive counts across all 181/201 formulas.

Why:

- one formula may support several Pattern concepts;
- some source phrases are broader than the normalized Pattern;
- some source phrases belong to Six Stages, Four Levels, disease context, or progression rather than Zang-Fu Pattern identity;
- the full corpus contains terminology variants.

Therefore:

**“4+ anchors” means at least four formula records currently confirmed to support the concept.**

It does **not** mean only four formulas exist.

---

# 3. Evidence-density priority scale

- **A+** — 5+ confirmed formula anchors or repeated across several systems/sources
- **A** — 3–4 strong formula anchors
- **B** — 2 strong anchors
- **C** — 1 strong anchor, but concept may still be clinically/canonically important
- **REL** — evidence mainly supports a relation/progression/compound structure rather than a standalone Pattern
- **TDIS** — evidence mainly represents TCM disease/context, not Pattern identity

# 13. Antigravity rules for consuming this file

1. Do not use evidence density as automatic permission to create a Pattern.
2. First compare with:
   - registry
   - library
   - aliases
   - relations
   - decision log
3. Exact Chinese identity outranks English wording.
4. Multiple formulas supporting the same Pattern increases confidence, but still does not determine canonical granularity.
5. Formula-specific compound phrases should usually be decomposed into graph relations.
6. TCM disease labels must remain separate from Pattern identity.
7. Preserve exact source wording under provenance.
8. When formula sources disagree on terminology, keep the disagreement rather than silently “correcting” one source.
9. Resolve formula names to canonical `formula.*` IDs only at repository implementation time.
10. Never infer acupuncture points from formula evidence.

# 14. What this inversion changes strategically

The Pattern Expansion queue should no longer be prioritized only by organ-system completeness.

It can now use three axes:

```text
Canonical value
    ×
Formula evidence density
    ×
Board / course relevance
```

For example:

- `Liver Qi Invading Stomach` has repeated formula evidence and strong clinical usefulness → early V2.
- a rare compound phrase found once on one formula page → hold as relation/context.
- `Kidney Jing Deficiency` may have fewer exact phrase matches but remains high canonical value because it is a foundational reusable Pattern.
- `Wei syndrome due X` may appear many times, but remains `tdis.*` context rather than becoming many Pattern IDs.

This prevents source frequency from becoming a blunt popularity contest.

# curriculum/theory/ — 基礎理論、四診、經絡學總論、醫古文

**收什麼:** 不屬於任何單一藥/穴/病,但每張卡都會用到的底層知識 ——
陰陽五行、藏象、氣血津液、病因病機總論、四診(舌診脈診)、八綱與各種辨證體系、
經絡學總論、醫古文/中醫術語英譯。

**不收什麼:** 「LU 經穴位表」→ `acupoints/`(那是東西不是原則)。
某個病的病機 → `conditions/`。

## 為什麼要單獨一個資料夾

這些材料的用法跟別的不一樣:它們不會變成一張卡,而是**被很多張卡引用**。
辨證分型的名稱(氣滯血瘀、肝鬱脾虛…)要全站一致,靠的就是這裡的定義;
舌脈的描述用語也一樣。之後如果卡片之間術語打架,回這個資料夾對答案。

醫古文/術語英譯放這裡,因為全站中英雙語標籤的譯法要統一 —— 同一個
「疏肝解鬱」在穴位卡和中藥卡不該翻成兩種英文。

## 這個資料夾是為了哪一層

BLUEPRINT 裡未來的**飲食生活建議層**(參考 chinesemedicineatlas 的食物頁,
但不放圖)。它要能同時吃進四種觀點,而且**地域 × 季節 × 年齡**三個維度會變:

| 維度 | 為什麼影響建議 |
|---|---|
| 中醫 | 四氣五味歸經、體質辨識 |
| 西醫 | 禁忌症、藥物交互(例:華法林 vs 維生素 K) |
| 營養學 | 熱量、蛋白質、微量元素 |
| 地域/季節/年齡 | 加州 vs 台灣、夏 vs 冬、小兒 vs 老人 —— 同一個證,建議不同 |

所以檔案進來時,如果知道它預設的地域或族群,寫進檔名或檔案開頭。一份寫給
台灣冬天的養生課,直接套給加州病人是錯的。

## 0. The governing change — read this first

**The content policy was retired and replaced** (`AGENTS.md`, top of file).

Old default: leave the field empty with a 待補 placeholder, wait for a gate.
That default produced 202 herbs sharing 26 template sentences, which passed all
eight validators and got reported to Ting as complete.

New default: **fill it from a professional source, cite per field, render it as
draft, review it in-app.** An empty dosage field is not safer than a sourced
one — it just moves the lookup somewhere untracked. This app is private and
internal.

Still handled carefully — meaning *fill, cite and flag*, never blank: needling
depth and angle, herb toxicity and maximum dose, pregnancy cautions,
herb–drug interactions.

**Applies to Codex identically.** Stop producing staging previews that wait for
a gate.

## 5. Standing rules adopted today

1. **Fill and cite. Never 待補.** (§0)
2. **Bilingual is structural, not aspirational.** A `_zh` field holding English
   is a defect. Knowledge links need at least one zh and one en source.
3. **No boilerplate ever.** If N records share a sentence it is a skeleton, and
   it is worse than empty because empty is honest.
4. **Final verification compares against an external professional site**, not
   only internal checks. A layer is not done while a benchmark source has whole
   sections we lack.
5. **Where two sources disagree, record both with attribution.** Never silently
   pick one, never present one source's number as consensus.
6. **Quality is measured, not asserted.** `validate-content-quality.js` before
   any "done".
7. **Links only, no copied images.** Direct URLs, never site-scoped search.

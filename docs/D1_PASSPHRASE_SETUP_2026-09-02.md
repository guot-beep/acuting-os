# 通行碼版:妳要做的事(約 10 分鐘)

寫給 Ting。**不碰 Cloudflare Access、不用收信、不用 PIN。** 第一次在一台裝置上開病例時輸入一次通行碼,
那台裝置 30 天內免再打。知識庫(穴位、方劑、中藥)完全不需要通行碼,跟現在一樣是公開的 ——
所以 acuting.com 被鎖住那種事不會再發生。

## 事 0:想一句通行碼

一句自己記得住、別人猜不到的話。可以是中文。

- 好的例子:`白虎湯加石膏四十克`、`診所後面那棵桂花樹`、`correct horse battery staple`
- 不要用:生日、電話、診所名字、`acuting123`
- 規則:中文一個字算 2 分、其他算 1 分,總分要 ≥ 16,字數 ≥ 8。
  (`白虎湯加石膏四十克` = 9 個中文字 = 18 分,夠。)

**先寫在紙上或密碼管理器裡。** 忘記的話沒有「忘記密碼」信可以收——只能重設(下面有寫,病例不會掉)。

## 事 1:把通行碼算成雜湊(在妳自己的電腦上)

PowerShell 貼這兩行:

```powershell
$env:Path = "C:\Program Files\nodejs;" + $env:Path
node C:\Projects\acuting-sqlite-tools\scripts\make-clinical-passphrase-hash.js
```

它會問兩次通行碼(打字不會顯示,正常),然後印出四行:

```
CLINICAL_PASS_SALT   = …
CLINICAL_PASS_HASH   = …
CLINICAL_PASS_ITER   = 30000
CLINICAL_TOKEN_SECRET= …
```

**把這四行貼給我。** 通行碼本身**不要**貼給我,也不要貼給任何人——
這四行是從通行碼算出來的,反推不回去。

> 忘記自己設的是哪一句?`node …\make-clinical-passphrase-hash.js --check` 可以只驗證不重設。

## 安全上誠實說

- 通行碼**只有妳知道**:雲端只存它的雜湊,我也看不到。但這也表示**忘了就得重設**。
- 這比 Cloudflare Access **弱一點**:Access 綁的是妳的 email 身分,通行碼是「誰知道誰進得去」。
  對一個人使用的診所系統,加上「錯 8 次鎖 15 分鐘」與「病例只放去識別化代號」,我認為夠。
- 病例仍然只放代號,不放姓名、完整生日、電話(D7 不變)。
- 之後 Cloudflare 的 PIN 事故修好、妳想換回 Access,程式不用改,只要換設定。

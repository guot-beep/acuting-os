# SOL 查證請求 — 17 個 outcome metric 的判讀來源

**這份可以整段貼給 SOL。** 下面「給 SOL 的訊息」那一節開始到結尾都是要貼的內容。

背景(不用貼):`data/clinical_cases/outcome_metrics.json` 共 27 個 metric,已依判讀來源分成三態。
`sourced` 4 筆、`no_published_threshold` 6 筆、`source_pending` 17 筆。這 17 筆就是這份要問的。
在 SOL 回覆之前,任何人都不得往這些記錄寫入數字閾值 —— `scripts/validate-metric-interpretation.js` 會擋。

# 給 SOL 的訊息(以下整段貼)

我在整理一個中醫診所的臨床療效追蹤欄位表,需要你幫忙查文獻來源。

## 我要的是什麼

每個指標我都要知道:**「變化多少才算臨床上有意義」這件事,文獻上有沒有具名的說法。**

**兩種答案我都要,而且同等有價值:**

- **A. 有** → 給我具名來源(作者、期刊、年份、DOI 或 PubMed 連結),以及那個來源實際說了什麼。
- **B. 沒有** → 明確告訴我「文獻上不存在公認閾值」。這是**結論**,不是失敗。我會把它記成定案,以後就不會有人再去「補」一個看起來合理的數字進去。

**最重要的一條:不確定就說不確定,不要給我一個估計值。**
這張表會進臨床病歷的判讀畫面。一個沒有出處的數字進去之後,下一個看到的人會把它當成標準。我寧可欄位空著寫「無公認閾值」,也不要一個查不到出處的數字。

## 請分清楚兩件事

有些指標的**量表**有出處,但**判讀閾值**沒有。這兩者要分開回答。

例如 `sleep_onset_minutes`:量表本身出自 Consensus Sleep Diary(Carney et al., Sleep 2012),這個我已經有了。但「入睡時間縮短幾分鐘算臨床有意義的改善」是另一個問題,那才是我要問的。

## 回覆格式(每個指標一段,照這個格式我才能直接套用)

```
### metric.xxx
判定: 有來源 / 無公認閾值 / 你也查不到
來源: 作者. 標題. 期刊. 年;卷(期):頁. [PubMed 或 DOI 連結]
它說了什麼: 一到兩句,用那個來源自己的說法,不要改寫成更確定的語氣
適用範圍: (若該閾值只適用於特定族群或情境,寫出來)
```

## 第一組:睡眠(3 個)

### metric.sleep_hours — 睡眠時數
- 單位:小時/晚,自述
- 量表:非驗證工具,就是一個原始數量
- 我想知道:成人每晚睡眠時數,專業學會(例如 AASM/SRS)有沒有具名的建議範圍?以及「增加幾小時算臨床有意義」有沒有說法?

### metric.sleep_onset_minutes — 入睡時間(躺下到睡著)
- 單位:分鐘,方向:越短越好
- 量表出處已有:Carney et al., *Sleep* 2012(Consensus Sleep Diary)
- 我想知道:**縮短幾分鐘**算臨床有意義的改善?失眠治療試驗(CBT-I 之類)是否有慣用的判定標準?

### metric.night_wakings — 夜醒次數
- 單位:次/晚,方向:越少越好
- 量表出處已有:同上 Consensus Sleep Diary
- 我想知道:**減少幾次**算臨床有意義?

## 第二組:婦科與生殖(9 個)

這一組多半是「正常範圍」而不是「變化幅度」的問題,請照實際情況回答。

### metric.cycle_length — 月經週期長度
- 單位:天,方向:因人而異
- 我想知道:婦產科學會(FIGO/ACOG 之類)對正常週期長度範圍有沒有具名定義?週期長度變化多少算臨床有意義?

### metric.bleeding_days — 經期天數
- 單位:天
- 我想知道:正常範圍的具名定義?多少天算過長?

### metric.menstrual_flow_volume — 月經量(量少/正常/量多)
- 單位:分類(scanty / normal / heavy)
- 我想知道:量少/正常/量多的判定標準有沒有具名來源?例如以失血量(mL)界定,或標準化的評分工具(PBAC 之類)?那些工具的臨床實用性如何?

### metric.menstrual_clots — 血塊(無/小/大)
- 單位:分類
- 我想知道:血塊大小的分級與臨床意義有沒有具名來源?還是這在文獻上其實只是描述性紀錄?

### metric.ovulation_confirmed — 確認排卵
- 單位:是/否/未知
- 我想知道:**哪一種證據組合才構成「確認排卵」**?(黃體期血清 progesterone、超音波追蹤、BBT、LH 試紙,各自的證據強度)有具名的判定標準嗎?

### metric.lh_surge — LH 高峰試紙
- 量表:尿液 LH 排卵試紙(OPK)
- 我想知道:判讀方式與偽陰性/偽陽性率有沒有具名來源?PCOS 這類情況下的可靠性?

### metric.bbt_pattern — 基礎體溫型態
- 單位:文字(如雙相型)
- 我想知道:「雙相型代表有排卵」這個判讀有沒有具名來源?它的敏感度/特異度文獻怎麼說?

### metric.endometrial_lining — 內膜厚度
- 單位:mm,經陰道超音波
- 我想知道:**幾 mm 算適合著床**有沒有具名來源?這個閾值在文獻上的爭議程度?

### metric.follicle_size — 卵泡大小
- 單位:mm,經陰道超音波
- 我想知道:達幾 mm 算成熟卵泡?自然週期與促排週期的標準是否不同?

- 我想知道:Rome IV 準則對排便頻率有沒有具名的判定(例如每週少於三次)?以及頻率變化多少算臨床有意義?

- 我想知道:更年期血管舒縮症狀試驗中,**每日次數減少多少**算臨床有意義?FDA 對這類試驗的療效終點有沒有具名指引?

## 第四組:針灸療程本身(3 個,這組問題不太一樣)

這三個是自由文字欄位,可能根本不該有「閾值」,而是需要一個**分類框架**。
請直接告訴我哪一種比較合適,包括「這個欄位不需要框架」也是有效答案。

### metric.post_treatment_reaction — 治療後反應
- 目前:自由文字。針後痠脹、疲倦、所謂「好轉反應」等
- 我想知道:針灸文獻上,**有沒有具名的框架區分「預期的治療後反應」與「需要留意的不良事件」**?
- 補充:安全性事件我另外記在 `adverse_reaction`,這一欄不記那些

### metric.adverse_reaction — 不良反應
- 目前:自由文字
- 我想知道:針灸不良事件的**嚴重度分級**有沒有標準化工具?(CTCAE 是否適用於針灸?針灸領域自己有沒有共識分級?)
- 我想知道:是否有針灸特有的不良事件標準化用語清單(STRICTA 或相關共識是否涵蓋)

### metric.effect_duration_days — 效果維持時間(天)
- 單位:天,方向:越長越好。臨床上用來決定療程間隔
- 我想知道:針灸療效維持時間有沒有具名的測量方式或判定標準?還是這在文獻上只是描述性的?

## 最後

如果某一組你查完覺得「這幾個其實都沒有公認閾值」,請直接這樣說,並且說明是**查過沒有**還是**不確定**。這兩者對我的意義不同:

- 「查過,文獻上沒有」→ 我記成定案,永久不再問

# (以下不用貼給 SOL)拿到回覆之後怎麼處理

1. `判定: 有來源` → 該筆改成 `interpretation_status: "sourced"`,填 `source: {name, url}` 與 `interpretation_en`(用來源自己的說法)
2. `判定: 無公認閾值` → 改成 `no_published_threshold`,並在 `interpretation_note_zh` 記下「SOL 查過,文獻上不存在」
3. `判定: 查不到` → 維持 `source_pending`
4. 改完跑 `node scripts/build-data.js` 與 `node scripts/validate-metric-interpretation.js`
5. **不要自己補任何一個 SOL 沒給出處的數字。** 那條 validator 會擋,而且那正是它存在的理由。

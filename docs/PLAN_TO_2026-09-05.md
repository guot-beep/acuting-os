## 2. 西藥卡:它是第五套命名空間,而且是最危險的一套

### 現況(12 筆,`data/medications/western_medications.json`)

```
med.letrozole · med.clomiphene_citrate · med.metformin · med.progesterone ·
med.estradiol · med.follitropin_alfa · med.menotropins · med.ganirelix ·
med.leuprolide · med.human_chorionic_gonadotropin · med.low_dose_aspirin ·
med.enoxaparin
```

全部是**生殖科用藥種子**(`status: fertility_medication_seed_for_review`)。

| 欄位 | 狀態 |
|---|---|
| `major_contraindications_en` | **12/12 全空** |
| `common_adverse_effects_en` | **12/12 全空** |

| 中文 | **0 個 `_zh` 欄位** |

### 為什麼這一層要比其他層更嚴

BLUEPRINT 的臨床北極星第一條就是**中西藥交互安全**。而西藥卡是
**「合理的編造」代價最高**的地方:

- 一個編出來的禁忌 → 你在診所會信它
- 一個漏掉的交互 → 病人在吃 warfarin 而你開了活血化瘀

`AGENTS.md` 已經把「藥物交互、劑量、孕期」列為要個別照顧的欄位。
**低階模型絕對不碰這一層**(派工單指定模型層級)。

### 開工前必須先決定的一件事:範圍

**不要做藥典。** 你需要的不是 1000 種藥,是**你的病人實際在吃的藥**。
建議範圍(約 60–80 種),照診所遇到的機率排:

```
① 抗凝/抗血小板   warfarin · apixaban · rivaroxaban · clopidogrel · aspirin
                  → 針灸最直接的安全問題(出血、拔針壓迫)
② 影響針灸判斷    類固醇 · 免疫抑制劑 · 化療 → 感染風險、禁針區
③ 慢性病常見      降壓 · 降糖 · 甲狀腺 · statin · PPI
④ 精神科          SSRI · SNRI · BZD · 情緒穩定劑 → 與安神類中藥交互
⑤ 止痛            NSAID · opioid · gabapentin
⑥ 婦科/生殖       已有的 12 筆 + 口服避孕藥 · HRT · tamoxifen · AI 類
```

### 建議的建構順序(照 D14)

| 步 | 產出 | 誰 |
|---|---|---|
| 1 | `data/config/medication_class_vocabulary.json` — 藥物分類詞彙表 | Claude |
| 2 | `docs/MEDICATION_CARD_TEMPLATE.md` — 含**交互作用分級**(見下) | Claude |
| 3 | `scripts/validate-medication-standard.js` | Claude |
| 4 | 匯入層 — 來源要定:**只用官方藥品資訊**(FDA label / DailyMed / NIH) | Claude 定,拓關填 |
| 5 | 內容 | **不給低階模型** |

**交互作用必須分級,不能只寫「可能有交互」**:

```
documented_clinical   有臨床報告
pharmacokinetic       CYP/P-gp 機轉明確
pharmacodynamic       作用疊加（出血、鎮靜）
theoretical           只有機轉推論
unknown               查不到 —— 這也是一個答案，而且要寫出來
```

**「查不到」比編一個出來有價值得多。**

**為什麼第 1 步在建新卡之前**:現有 150 筆裡有 95 筆沒有安全警訊。

青光眼是病人會當成小毛病拿來針灸的東西。糖尿病與甲狀腺則是它們會改變
針灸與用藥安全判斷。
